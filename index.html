Color Calculator

Color coordinate converter

This tool allows you to pick a color and see how it is represented in several different color systems, or specify a color in one of said systems to see how it is represented in the others. For now, the only supported color systems are RGB and YCbCr.

Find overlay color

This tool finds a partially-transparent color that, when layered over a given background color, produces the desired resulting color. In web design, using transparent colors allows you to change a background color without needing to adjust all the colors that appear on top of it.
